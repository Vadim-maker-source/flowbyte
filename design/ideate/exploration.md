# FLOWBYTE visual exploration

All directions visualize the same Home / Mission Map at 393 × 852 and answer the same questions: where am I, what is complete, and what comes next.

## A — Technical

Principle: a compact learning instrument.

- Layout: strict top status row, compact Byte identity block, vertical lesson index with thin separators, fixed bottom CTA.
- Palette: graphite, neutral elevated surfaces, one electric-blue accent.
- Components: rectangular lesson rows, precise monospaced metadata, minimal depth.
- Optimizes: speed, clarity, developer-tool credibility.
- Sacrifices: emotional warmth; can feel advanced to a first-time learner.

## B — Soft Future

Principle: a calm, friendly guide that still respects the learner.

- Layout: compact Byte/XP header, one current-module summary, a connected mission route with clear completed/active/locked states, anchored Continue action.
- Palette: dark navy, crisp blue primary, restrained mint only for success and Byte energy.
- Components: solid 14–18 px-radius surfaces, thin outlines, subtle elevation, geometric 2D Byte.
- Optimizes: approachability, comprehension, teenage fit, and a distinct educational identity.
- Sacrifices: slightly less information density than Technical.

## C — Mission Control

Principle: every lesson is an operational checkpoint.

- Layout: compact mission header, map-like route, active checkpoint detail, status strip.
- Palette: near-black navy, steel blue, signal cyan.
- Components: route nodes, coordinate-like labels, restrained HUD vocabulary.
- Optimizes: motivation, progression, final-mission continuity.
- Sacrifices: the mission metaphor can compete with lesson content and drift toward game HUD styling.

## Decision

Selected: **B — Soft Future**.

It best balances clarity, contemporary polish, educational friendliness, and the 12–17 audience. The route logic from Mission Control is retained only where it improves progress comprehension; the dense typography from Technical is retained inside code and trace surfaces. The result is not a recolor: Soft Future uses a guided route as its organizing principle, while keeping decoration subordinate to content.
